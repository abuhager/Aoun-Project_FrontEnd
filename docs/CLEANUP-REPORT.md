## التغييرات

- توحيد `DeliveryState` بدل تعريفه مرتين، واعتماد مكونات Dashboard على نوع `Item` الأصلي بدل المرور عبر Hook.
- إزالة إعادة تصدير الأنواع غير المستخدمة من `useDashboard` و`ItemsTable`، وحصر `NumericSettingKey` داخل ملفه.
- حذف تعريف `UserRating` غير المستهلك في الواجهة. لم يُحذف مسار من Backend. اختبار nullable أصبح يفحص `PendingRatingResponse` المستخدم فعلًا، بما في ذلك `pendingRating` و`donor` و`bookedBy`.
- تصحيح توضيح الكوتا الشهرية في لوحة الإدارة: الطلبات الملغاة محسوبة أيضًا، بما يطابق قاعدة العمل الموجودة في Backend.
- إزالة سجلات تشخيص نموذج الطلب من اختبار Playwright، واستبدال الانتظار الثابت بمراقبة رد POST للمسار المحدد وإثبات حالة نجاحه. رسائل فشل الاختبار بقيت متاحة.
- تحديث `@humanfs/node` من `0.16.7` إلى `0.16.8` في ملف القفل، مع تحديث `@humanfs/core` وإضافة `@humanfs/types` التي يحتاجها التصحيح. لا توجد ترقية رئيسية لـNext أو React أو ESLint.

## ما لم يُحذف ولم يتغير

لا توجد ملفات كاملة مطلوب حذفها في هذه الدفعة. تقارير Playwright القديمة واعتماد Faker أُزيلا سابقًا، وليسا حذفًا جديدًا. لا تحذف `docs/` أو `test/` أو `tests/` أو الأصول المستخدمة.

حسابات Demo وإعدادات إظهارها بقيت كما هي. لم تتغير صفحة إلى Client أو Server، ولم يتغير منطق تسجيل الدخول أو العروض أو الحجز. لا تغييرات في إعدادات Vercel أو ملفات البيئة.

## التطبيق

احفظ نسخة من تعديلاتك المحلية أولًا، ثم ادمج ملفات مجلد `aoun-frontend` المرفق داخل مشروعك مع استبدال الملفات المطابقة فقط. الأرشيف ليس مشروعًا كاملًا؛ لا تحذف مجلد المشروع القديم.

```powershell
npm ci
npm run verify
npm run build
```

لا تستبدل `.env.local`. إذا فشل بناء الإنتاج بسبب Origins محلية أو متغير ناقص، احتفظ بسياسة HTTPS واضبط القيم الصحيحة؛ لا تعطل الحماية.
