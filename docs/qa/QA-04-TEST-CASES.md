# QA04 E2E Scenarios

| ID | السيناريو | النتيجة المتوقعة |
|---|---|---|
| QA04-E2E-001 | فتح الموقع كزائر ثم Browse | الموقع والبيانات العامة تعمل |
| QA04-E2E-002 | Login بحساب الطالب | ينتقل إلى Dashboard |
| QA04-E2E-003 | الطالب ينشئ طلب تبرع | يظهر الطلب في قائمته |
| QA04-E2E-004 | المتبرع يسجل ويفتح الطلب | يرى زر تقديم العرض |
| QA04-E2E-005 | المتبرع يرسل عرضًا | العرض Pending ويظهر لصاحب الطلب |
| QA04-E2E-006 | الطالب يقبل العرض | Accepted واحد، والآخر Rejected |
| QA04-E2E-007 | المتبرع المرفوض يفتح الغرض المقبول | لا يرى التفاصيل الخاصة |
| QA04-E2E-008 | Logout ثم Back | لا تعود بيانات محمية |
| QA04-E2E-009 | فتح صفحة Browse الثانية ثم التفاصيل ثم Back | العودة إلى `?page=2` |

هذه المرحلة توثيق السيناريوهات. لاحقًا نكتبها بـ Playwright أو أداة E2E مناسبة.
